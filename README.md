# Proyecto para presentar mi portfolio professional

Sitio web personal y portfolio profesional desarrollado con mis habilidades como front-end sénior. Diseñado con un enfoque *pixel-perfect*, rendimiento optimizado, accesibilidad y cero dependencias pesadas.

## 🛠️ Tech Stack & Arquitectura

* **HTML5 Semántico:** Estructura limpia y optimizada para accesibilidad (a11y) y SEO técnico.
* **CSS3 Moderno:** Maquetación fluida mediante `clamp()`, variables CSS, layout con Flexbox/Grid y selectores avanzados (`:has()`).
* **JavaScript (ES6+):** Lógica ligera e interactividad sin dependencias (*vanilla JS*).
* **Media Optimization:** Recursos multimedia optimizados en formato WebM de alta compresión para minimizar tiempos de carga (Core Web Vitals).

## 🚀 Despliegue & CI/CD
El proyecto está configurado para despliegue continuo en **Vercel** vinculado a la rama `main` de este repositorio.
